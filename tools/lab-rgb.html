表示の見方

  • RGB: 選んだ色空間・bit 深度のコード値です。ガンマ補正済み (画像ファイルに入る値) です。 詳しく
  • 色域: 「範囲外」のときは、その色空間で表せない色なので 0 か最大値に切り詰めています (クリップ)。そのぶん色が変わり、ΔE2000 が大きくなります。詳しく
  • ΔE2000: 入力の Lab と、丸めた RGB から逆算した Lab の差です。 四捨五入 (量子化) のずれだけなら 8bit でも 0.5 未満がふつうです。詳しく
  • Lab (D50): このツールの基準の白 (ICC D50) で表した Lab です。D50 以外の白を選んだときは、 Bradford 色順応で D50 に換算してから RGB を計算します。詳しく
  • 色見本: 選んだ色空間のまま表示します。モニターがその色域に対応していない場合や、 古いブラウザでは正しい色になりません。正確な値は数値で確かめてください。

計算の流れ

  1. Lab (選んだ白) → XYZ → Bradford 色順応で D50 の XYZ へ
  2. XYZ (D50) → リニア RGB (3×3 の行列。原色と白色点から導出した行列に、 D50 → 色空間の白の色順応を掛け合わせたもの) 詳しく
  3. ガンマ補正 (sRGB・Display P3 は IEC 61966-2-1 の式、Adobe RGB は 563/256 乗)
  4. 0〜1 にクリップしてコード値へ。8/16bit は四捨五入 (half-up)、32bit は float32 に丸める 詳しく
  5. コード値から逆の順で Lab を求め、入力との ΔE2000 を計算

RGB → Lab は 5 → 1 の逆の順です。

この計算を信頼できる理由

  • 行列・白色点・ガンマの指数は、Python の色計算ライブラリ colour-science 0.4.7 で作り、このページに埋め込んでいます。 ページの JavaScript は計算式だけを持ちます。
  • ページを開くたびに、Python で計算した答え 210 件 (色域外の色を含む) と このページの結果を照合し、上に結果を表示します。
  • 開発時のテストで、ランダムな数百色について 3 つの色空間 × 6 つの白色点 × 3 つの bit 深度の 両方向で、Python のツール (colorchart) と結果が一致することを確かめています。
  • 使った数値はすべて、このページと同じ名前の JSON ファイル (拡張子 .json) に入っています。

用語

ここでは一言だけ説明しています。考え方はナレッジにまとめています。

Lab (L*a*b*)
色を見え方で表す 3 つの数。L* は明るさ (0 = 黒、100 = 白)、a* は赤 (+) ⇔ 緑 (−)、b* は黄 (+) ⇔ 青 (−)。 詳しく
色域
その RGB 色空間で表せる色の範囲。範囲の外の色は RGB の 0〜最大値に収まらない。 詳しく
白色点
「何を白とみなすか」の基準。同じ色でも、基準の白が変わると Lab の数値が変わる。 詳しく
色順応
白の基準が違う Lab どうしを換算する計算。このツールは Bradford 法で統一。 詳しく
ガンマ
明るさの数値を、目の感じ方に合わせて曲げる処理。画像の RGB はふつう補正済み。 詳しく
量子化
連続した値を 0〜255 などの整数にすること。四捨五入 (half-up) で丸める。 詳しく
クリップ
表せる範囲を超えた値を端 (0 か最大値) に切り詰めること。色が変わる。 詳しく
ΔE2000
2 つの色の違いを表す数。1 前後が「やっと違いがわかる」目安。 詳しく
