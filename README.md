# color-science-docs

色管理 (カラーマネジメント) の用語と考え方、カラーチャートのレポートをまとめたドキュメントです。
GitHub Pages で公開しています: https://2jo-code.github.io/color-science-docs/

| ページ | 内容 |
|---|---|
| [knowledge.html](knowledge.html) | 色の用語と考え方 (色空間、Lab、白色点と色順応、ガンマ、量子化、ΔE2000 など) |
| [reports/charts.html](reports/charts.html) | 全カラーチャートの Lab 値一覧 (白色点ごと) |
| `reports/compare_*.html` | 8bit / 16bit / 32bit の精度比較 |

レポートはツール [dev-colormanagement](https://github.com/2JO-code/dev-colormanagement) の
`colorchart reference` / `colorchart compare` で作っています。

## 手元で見るには

`index.html` をブラウザで開くだけで見られます (外部ファイルの読み込みはありません)。
